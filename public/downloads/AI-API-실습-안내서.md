# AI API 연결 첫 실습 안내서

이 안내서는 코딩이 처음인 분이 샘플 소스를 실행하고, 질문 문구를 바꾸고, 자주 발생하는 오류를 스스로 확인하도록 돕습니다.

## 1. 준비물

- 인터넷에 연결된 개인 노트북
- Node.js 20 이상
- 코드 편집기
- OpenAI API 키와 사용 가능한 API 크레딧
- 다운로드한 `ai-api-workshop-sample.zip`

## 2. 프로젝트 실행

1. ZIP 파일의 압축을 풉니다.
2. 압축을 푼 폴더를 코드 편집기에서 엽니다.
3. 터미널에서 `npm install`을 실행합니다.
4. `.env.example` 파일을 복사해 `.env` 파일을 만듭니다.
5. `.env` 파일의 `OPENAI_API_KEY` 값을 자신의 키로 바꿉니다.
6. `npm start`를 실행합니다.
7. 브라우저에서 `http://localhost:3000`을 엽니다.

```env
OPENAI_API_KEY=여기에_본인의_API_키
OPENAI_MODEL=gpt-5-mini
PORT=3000
```

> `.env` 파일과 실제 API 키는 GitHub, 채팅방, 화면 캡처에 올리지 마세요.

## 3. 코드 흐름

1. `public/index.html`이 입력 화면을 보여 줍니다.
2. `public/app.js`가 입력값을 `/api/ask`로 전송합니다.
3. `server.mjs`가 서버에 보관된 API 키로 OpenAI Responses API를 호출합니다.
4. 받은 답변을 다시 브라우저 화면에 표시합니다.

## 4. 나만의 프로그램으로 바꾸기

`server.mjs`의 `instructions`를 수정해 프로그램의 역할을 바꿀 수 있습니다.

```js
instructions: "입력된 문장을 초보자가 이해하기 쉬운 한국어로 세 줄 요약하세요.",
```

활용 예시:

- 회의 내용 요약기
- 블로그 제목 생성기
- 영어 문장 교정기
- 여행 일정 추천기
- 공부 문제 생성기

## 5. 자주 발생하는 오류

| 증상 | 확인할 내용 |
|---|---|
| API 키 설정 안내가 표시됨 | `.env` 파일 이름과 `OPENAI_API_KEY` 값을 확인한 뒤 서버를 다시 실행합니다. |
| 401 오류 | API 키가 정확한지, 공백이 포함되지 않았는지 확인합니다. |
| 429 오류 | 사용 한도, 결제 상태 또는 요청 빈도를 확인합니다. |
| 모델 오류 | `.env`의 `OPENAI_MODEL`을 계정에서 사용할 수 있는 모델로 변경합니다. |
| 화면이 열리지 않음 | 터미널에서 `npm start`가 실행 중인지 확인합니다. |
| 변경 내용이 반영되지 않음 | 서버를 종료한 뒤 다시 실행하고 브라우저를 새로고침합니다. |

## 6. 완료 체크리스트

- [ ] 샘플 화면을 열었다.
- [ ] API 키를 `.env`에만 저장했다.
- [ ] AI의 첫 답변을 받았다.
- [ ] `instructions`를 수정해 결과 변화를 확인했다.
- [ ] 오류 메시지를 읽고 확인할 위치를 안다.
